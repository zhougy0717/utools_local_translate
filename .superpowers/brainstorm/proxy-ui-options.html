词典下载界面中的代理入口设计

我们已经添加了超链接，现在讨论其位置和形式是否需要进一步优化，以及移除 /proxy 命令的影响。

A

顶部提示框 (当前设计)

在界面顶部显示一个绿色的 Notice 区域，包含“配置全局代理”链接。这种方式最显眼，适合在下载前引导用户检查网络。

🌐
网络代理： 如遇下载缓慢或失败，请尝试 配置全局代理。
B

底部操作区链接 (更克制)

将代理配置链接放在“开始下载”按钮旁边，或在底部以次要按钮/链接形式存在。视觉干扰较小，适合认为代理配置是“备选方案”的场景。

后续计划：移除 /proxy 命令

优点

  • 精简了主命令空间，不再对普通用户暴露“高级”配置。
  • 保持了 UI 驱动的交互风格，减少了对 Slash 命令的依赖。

风险 (待确认)

  • 其他翻译模式： 如果用户当前使用 Ollama 且需要代理，目前尚未在 Ollama 配置界面提供入口。
  • 已开启代理无法关闭： 移除命令后，如果用户想关闭代理，必须先进入离线词典配置页。
