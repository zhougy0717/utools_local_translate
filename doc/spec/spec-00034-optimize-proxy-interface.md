# Spec 00034: 代理设置界面优化与模块化控制

## 背景 (Overview)
当前插件的代理设置界面较为臃肿，且采取“全局开关”的模式，导致用户在某些需要代理（如词典下载、远程 LLM）和不需要代理（如本地接口）的场景下切换非常繁琐。

本方案旨在优化代理配置界面的 UX，并实现“配置与控制分离”：代理页面仅负责配置代理服务器信息，各功能模块（如离线词典下载、Ollama 端）自主决定是否使用该代理。

## 目标 (Goals)
1.  **极简代理配置**：采用行内布局，将原本分散的 Host/Port/Save 按钮整合到一行，支持快速保存。
2.  **模块化代理控制**：移除全局代理开关，在离线词典配置、Ollama 配置等界面分别提供独立的“使用代理”开关。
3.  **视觉统一**：各模块的代理开关风格与 Ollama 现有的 `toggle-switch` 保持一致。

## 详细设计 (Detailed Design)

### 1. 代理设置界面 (`src/config/proxy-config.html`)
- **移除内容**：
    - 删除顶部的 “启用全局代理” (`proxy-enabled`) 勾选框。
    - 删除底部的 “保存配置并退出”、“取消” 按钮组。
    - 删除 “返回离线词典配置” 链接。
- **布局变更**：
    - **主要行 (Main Row)**：采用 Flex 布局，依次排列：代理类型 (HTTP/SOCKS5)、Host (127.0.0.1)、Port (1080)。
    - **保存按钮**：在 Port 输入框右侧新增一个蓝色的 **✓** 按钮 (32x32px)。
- **交互逻辑**：
    - 点击 **✓** 按钮：执行 `saveProxyConfig`。**不再自动关闭面板**，以便用户在保存后继续进行连通性测试或其他操作。
    - 认证字段、测试按钮保留，但在布局上进一步紧凑化（减少间距）。

### 2. 离线词典配置界面 (`src/backends/dict/dict-config.html`)
- **新增元素**：
    - 在下载节点选择上方增加一个代理控制栏 (`.notice` 区域内或下方)。
    - 使用与 Ollama 风格一致的 `toggle-switch` 组件。
    - 标签显示为 `使用代理下载`。
- **配置同步**：
    - 在 `DICT_DEFAULTS` 中增加 `useProxy: false` 配置项。
    - 渲染器加载时从 `api.getProxyConfig()` 获取状态，变更时实时保存。
    - 启动下载任务时，将 `useProxy` 状态传递给下载 API。

### 3. 数据结构与底层逻辑变更
- **保留事件通知机制**：必须保留 `ProxyService` 中的 `EVENT_PROXY_CONFIG_CHANGED` 事件广播。当用户在配置页面点击 **✓** 按钮保存基础信息（Host/Port 等）后，继续向所有后端模块发出变更通知，以便各模块能够即时重载最新的代理参数。
- **AppConfig** (`src/utils/app_config.js`):
    - 保持原结构，但前端不再提供修改全局 `proxy.enabled` 的入口。底层 `getProxy()` 逻辑调整为支持 `forceEnabled` 模式，确保只要模块内部选用了代理，即便全局 `enabled` 为 false，也能获取到配置信息。
- **DictConfig** (`src/backends/dict/config.js`):
    - `DICT_DEFAULTS` 加入 `useProxy: false`。

## 视觉标准 (Visual Standards)
- **开关风格**：使用 `ollama-prompt-config.html` 中的 CSS 样式：
    - `.toggle-switch`: 宽 36px, 高 18px。
    - `.slider`: 圆角 18px，开启时背景颜色为 `--primary-color` (#2ea44f)。
- **按钮风格**：行内保存按钮（✓）背景色为蓝色 (#3b82f6)，确保一眼识别。

## 测试计划 (Test Plan)
1.  **代理配置**：修改代理参数，点击 ✓，确认配置已保存但面板保持打开。
2.  **网络测试**：在代理页面点击“测试连接”，确认其依然能正常工作。
3.  **离线词典下载**：
    - 开启“使用代理”，确认下载器能够识别并使用代理配置。
    - 关闭“使用代理”，确认下载器直连下载源。
