# Spec-00032: 优化斜线命令视觉表现 (Slash Command Visual Optimization)

## 1. 背景 (Background)
目前的斜线命令（`/`）列表在 uTools 中呈现为纯文本形式。用户反馈其视觉表现不够美观，主要痛点包括：
*   **文字堆砌**：描述过长，且包含冗余的命令提示（如 `/mode`）。
*   **缺乏图标**：所有条目都没有图标，视觉识别度低，无法快速定位功能。
*   **布局凌乱**：状态显示（如 ✅、⚠️、🌟）在描述中的排列不够规整。

## 2. 目标 (Goals)
*   **图标化**：为根命令和子命令引入一致、美观的视觉图标。
*   **精简描述**：缩减每个条目的描述行文字，突出其核心功能或当前状态。
*   **视觉层级**：通过标题和描述的差异化，清晰区分“当前激活状态”与“待执行操作”。

## 3. 详细设计 (Detailed Design)

### 3.1 根命令列表设计 (`/` 输入时)
在 `src/commands/index.js` 中，优化匹配出的命令列表项。

| 命令 | 原始方案 | 优化方案 (标题 + 描述) | 图标 (建议) |
| :--- | :--- | :--- | :--- |
| **`/mode`** | `切换翻译使用的模型或离线词典 (/mode)` | **选择翻译模式**<br>`当前：离线词典 / Ollama / LibreTranslate` | 🔄 (切换图标) |
| **`/libre`** | `设置 LibreTranslate 服务器地址和 API Key (/libre <url> [key])` | **配置 LibreTranslate**<br>`设置服务器地址与 API Key` | 🌐 (网络图标) |

### 3.2 模式选择列表设计 (`/mode` 输入时)
在 `src/commands/mode.js` 中，优化各模式的列表项展示。

*   **当前激活项**：
    *   标题：`${mode.title} (已激活 🌟)`
    *   描述：`✅ 数据已就绪 — ${mode.summary}` (如：ecdict 离线词典进行快速查词)
    *   图标：使用该模式的专属图标。
*   **待切换/未就绪项**：
    *   标题：`${mode.title}`
    *   描述：`⚠️ 未就绪，点击配置 / 🟢 服务已联通 — 使用 ${mode.summary}`
    *   图标：使用该模式的专属图标。

### 3.3 LibreTranslate 配置列表设计 (`/libre` 输入时)
在 `src/commands/libre.js` 中，优化配置项展示。
*   标题：`当前配置: <URL>`
*   描述：`🟢 连接正常 (点击重新验证/保存)`
*   图标：📡 (连接图标)

### 3.4 图标管理 (Icon Management)
我们将采用 **Base64 内置图标** 策略：
1.  在 `src/commands/` 目录下创建一个 `icons.js` 统一存储 Base64 格式的小图标。
2.  各命令文件从 `icons.js` 中引用并赋值给列表项的 `icon` 属性。
3.  确保图标在 uTools 的亮白和深色模式下都有良好的对比度。

## 4. 实现路径 (Implementation Path)
1.  **准备图标库**：搜集并转换 4-5 个核心图标（模式选择、网络配置、勾选/激活、字典说明）为 Base64 字符串。
2.  **更新 `index.js`**：调整根列表生成的 `title`、`description` 并注入相应图标。
3.  **更新 `mode.js`**：调整模式列表的生成逻辑，精简描述并增加激活状态标识。
4.  **更新 `libre.js`**：优化配置页面的描述格式。

## 5. 验收标准 (Acceptance Criteria)
*   [ ] 输入 `/` 后，列表项均有对应的图标显示。
*   [ ] 所有描述行不再包含如 `(/mode)` 这样的手动命令提示。
*   [ ] 当前选中的翻译模式能够通过标题后缀（🌟）和描述前缀（✅）显著区分。
*   [ ] 文字对齐整洁，没有超过 2 行的长文本。
